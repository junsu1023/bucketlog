# 로드맵 — BucketLog

> 버전 0.1 · 2026-08-17

---

## 원칙

1. **각 Phase는 그 자체로 출시 가능하다.** 다음 Phase를 기다려야 쓸 만해지는 설계는 잘못된 것입니다
2. **Phase 0은 백엔드 없이 완성된다.** 서버 구축을 이유로 출시가 늦어지면 안 됩니다
3. **종료 조건을 만족하지 못하면 다음으로 넘어가지 않는다.** 기능을 늘리기 전에 리텐션부터 확인합니다

## Phase 0 — 기록이 되는 앱 (MVP)

**목표: 나 혼자 1년을 써도 만족스러운 기록 앱**

### 범위

```
✅ 목표 CRUD (한 번 하기 / 반복하기)
✅ 상태 3종 (진행 중 / 완료 / 접어둠)
✅ 기록 3종 (퀵 체크인 / 진행 기록 / 완료 인증)
✅ 사진 첨부 (최대 5장) + 로컬 이미지 파이프라인
✅ 목표 상세 타임라인
✅ 홈 (올해의 버킷 · 연도 전환 · 언젠가)
✅ 보관함 (완료 / 접어둠)
✅ 온보딩 프리셋 목표
✅ 회고 프롬프트
✅ 알림 3종 (월간 회고 · 스마트 넛지 · 설정)
✅ 백업 / 복원
✅ 다크 · 라이트

❌ 백엔드 · 로그인 · 동기화
❌ 위젯
❌ 소셜
❌ 결제
```

### 종료 조건

```
□ 퀵 체크인 3초 이내
□ 목표 50개 · 기록 300개에서 홈 스크롤 60fps
□ 백업 → 재설치 → 복원이 사진까지 정상
□ 알림 예산(주 1회)이 실제로 지켜짐
□ 본인이 2주간 실제 목표로 사용해도 불편 없음
□ Android / iOS 스토어 출시
```

**예상 6주** (파트타임 기준). 상세 주차별 계획은 `docs/MVP-SCOPE.md` §4.

## Phase 1 — 돌아올 이유가 생기는 앱

**목표: 리텐션 강화 + 수익화 시작**

### 범위

```
✅ 위젯 (Android Glance / iOS WidgetKit) — Android는 Phase 0 안에서 먼저 구현됨(아래 참고)
✅ 작년 오늘 (MVP에서 P1이었다면 여기서 완성)
✅ 전체 타임라인 뷰
✅ 통계 (카테고리 분포 · 월별 완료 추이)
✅ 완료 카드 공유 (인스타 스토리 규격)
✅ 연말 회고 리포트  ← 12월 목표
✅ 연말 이월 플로우
✅ 로그인 + 클라우드 동기화  ← 프리미엄
✅ 결제 / 구독 도입
```

### 핵심

**위젯이 이 Phase의 주인공입니다.** 이 앱의 근본 문제("앱을 열 이유가 없다")를 구조적으로 푸는 유일한 기능입니다. 앱을 열지 않아도 목표가 눈에 들어오고, 그게 결국 앱을 열게 만듭니다.

**Android 위젯은 계획을 바꿔 Phase 0 중에 먼저 구현했습니다** — "진행 중 목표 1~3개 + 남은 일수"를
한 위젯에 담는 대신, 한 번에 하나만 보여주는 위젯 3종("오늘의 기억"/"지금 어때요"/"마감 임박")으로
나눴습니다. 여러 목표를 리스트로 나열하면 홈 화면에 상시 체크리스트가 떠 있는 셈이 되어
CLAUDE.md 절대 규칙 1번(스트릭·습관 트래커 금지)과 충돌하기 때문입니다. 각 위젯은 N-02/H-07/N-04의
기존 선정 로직을 그대로 재사용합니다(`GetThrowbackUseCase`/`PickNudgeTargetUseCase`/
`PickDueSoonGoalUseCase`). iOS(WidgetKit)는 아직 미구현 — Xcode Widget Extension 타깃과 App
Group 설정이 먼저 필요합니다. 자세한 내용은 `test.md` 참고.

**연말 회고 리포트는 12월에 맞춰 반드시 완성하세요.** 이 앱에서 유료 전환이 가장 많이 일어나는 시점이고, 1년에 한 번뿐인 기회입니다. 늦으면 다음 해까지 기다려야 합니다.

### 종료 조건

```
□ 위젯 설치율 30% 이상
□ D30 리텐션 25% 이상
□ 유료 전환율 2% 이상
□ 연말 회고 리포트 열람률 40% 이상
```

## Phase 2 — 함께 보는 앱

**목표: 조심스럽게 소셜 도입**

```
✅ 목표 공유 링크 (읽기 전용 웹뷰)
✅ 함께하는 목표 (2인 이상 공동 목표)
✅ 친구의 완료 소식 (푸시 아님, 앱 내 확인)
```

### 경고

**소셜은 이 앱에서 양날의 검입니다.** 이 제품의 가치는 "혼자 조용히 기록하는 것"인데, 소셜은 그걸 전시로 바꿉니다. 유저가 남에게 보여줄 만한 목표만 적기 시작하면 제품이 무너집니다.

따라서:
- 피드를 만들지 마세요. 좋아요·팔로우도 안 됩니다
- 공유는 항상 **유저가 명시적으로 고른 것만**
- 기본은 언제나 비공개

**Phase 1에서 리텐션이 확보되지 않았다면 진입하지 마세요.** 사람이 없는 소셜은 앱을 텅 비어 보이게 만들어 오히려 손해입니다.
