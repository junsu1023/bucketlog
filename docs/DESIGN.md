# 디자인 & 톤 가이드 — BucketLog

> UI 문구를 작성할 때 반드시 참조하세요. **이 앱의 차별점은 기능이 아니라 톤입니다.**
> 버전 0.1 · 2026-08-17

---

## 1. 톤의 원칙

이 앱은 사람의 "못 지킨 것"을 다룹니다. 대부분의 목표는 완료되지 않고, 그건 정상입니다.

> ### 이 앱은 코치가 아니라 일기장이다.

성과를 평가하지 않고, 재촉하지 않고, 기록을 도울 뿐입니다.

| | 하지 않음 | 함 |
|---|---|---|
| 역할 | 코치 · 트레이너 | 일기장 · 기록 도구 |
| 초점 | 달성률 · 성과 | 경험 · 기억 |
| 어조 | 독려 · 채찍질 | 담담한 안내 |
| 미완료 | 실패 | 아직 하지 않은 것 |

## 2. 금지어

**아래 단어를 UI에 쓰지 마세요.**

| 금지 | 대신 |
|---|---|
| 포기 | 접어두기 / 안 하기로 하기 |
| 실패 | (쓰지 않음) |
| 달성률 · 성공률 | (수치 자체를 강조하지 않음) |
| 분발 · 노력 · 파이팅 | (쓰지 않음) |
| 미달성 · 놓친 | 아직 |
| 목표 관리 | 기록 |
| 습관 · 스트릭 · 연속 | (쓰지 않음 — 이 앱은 습관 앱이 아님) |
| D-1 · 마지막 기회 | 마감일이 다가와요 |

## 3. 상황별 문구

### 접어두기

```
버튼         이건 안 하기로 하기
확인 제목     이 목표를 접어둘까요?
확인 본문     보관함으로 옮겨져요. 생각이 바뀌면 언제든 다시 꺼낼 수 있어요.
이유 입력     왜 마음이 바뀌었나요?  (선택)
완료 토스트   접어뒀어요. 보관함에 있어요.
```

**"정말 포기하시겠습니까?" 같은 문구를 절대 쓰지 마세요.** 접어두는 건 나쁜 일이 아니고, 오히려 목록을 정리하는 건강한 행동입니다.

### 완료

```
버튼         완료했어요
회고 안내     남기고 싶은 말이 있나요?  (건너뛸 수 있어요)
완료 토스트   기록했어요.
```

과한 축하(폭죽, "축하합니다!!!")는 피합니다. 짧은 애니메이션 하나면 충분합니다. 요란한 축하는 다음 번 완료의 기대치를 올리고, 조용한 목표를 완료하기 부담스럽게 만듭니다.

### 빈 상태

```
홈 (목표 없음)
  올해 하고 싶은 걸 하나 적어볼까요?
  [예시에서 고르기]  [직접 쓰기]

목표 상세 (기록 없음)
  아직 기록이 없어요.
  한 줄이라도 남겨두면 나중에 반가워요.

보관함 (완료 없음)
  완료한 것들이 여기 모여요.
```

### 퀵 체크인 플레이스홀더

```
지금 어때요?
한 줄만 남겨도 좋아요
```

### 회고 프롬프트

완료 시 랜덤으로 하나 제시. **[다른 질문]** 과 **[건너뛰기]** 를 항상 함께 둡니다.

```
공통    가장 기억에 남는 순간은?
        생각과 달랐던 점이 있나요?
        누구랑 함께했나요?
        이걸 하기 전의 나에게 한마디 한다면?
여행    어떤 장면이 제일 오래 남을까요?
도전    가장 힘들었던 순간은?
배움    무엇을 새로 알게 됐나요?
관계    어떤 이야기를 나눴나요?
```

### 알림

`docs/NOTIFICATIONS.md`에 종류별 문구 규칙이 있습니다. 공통 원칙은 하나입니다.

> **숫자로 평가하지 말고, 질문으로 초대할 것.**

```
❌  "이번 달 목표를 3개 중 0개 달성했어요"
✅  "9월이 지나갔어요. 이번 달엔 어떤 걸 했나요?"
```

## 4. 시각 방향

### 컨셉

**"오래 두고 볼 사진첩"**

- 사진이 주인공. UI는 배경으로 물러남
- 장식보다 여백
- 애니메이션은 절제 — 완료 순간에만 짧게

### 컬러

라이트/다크 모두 지원하고, **다크를 기본**으로 합니다 (사진이 가장 잘 살아납니다).

| 역할 | 라이트 | 다크 |
|---|---|---|
| 배경 | `#FAF9F7` (따뜻한 오프화이트) | `#14120F` (따뜻한 블랙) |
| 표면 | `#FFFFFF` | `#211E1A` |
| 본문 | `#1C1917` | `#EDE9E3` |
| 보조 텍스트 | `#78716C` | `#A8A29E` |
| 강조 | `#B45309` (앰버) | `#F59E0B` |
| 완료 | `#4D7C0F` (올리브) | `#84CC16` |
| 접어둠 | `#78716C` (중성 회색) | `#78716C` |

**접어둠 상태에 빨강을 쓰지 마세요.** 빨강은 오류·실패의 신호입니다. 접어둔 목표는 채도를 낮춘 중성색으로, 조용히 물러나 있게 합니다.

**완료에 초록을 쓰되 형광은 피합니다.** 올리브 계열이 이 앱의 차분한 톤에 맞습니다.

### 타이포

| 용도 | 스타일 |
|---|---|
| 목표 제목 | 세리프 또는 굵은 산세리프 — 무게감 |
| 본문 / 메모 | 산세리프, 행간 넉넉히 (1.6) |
| 날짜 / 수치 | 모노스페이스 — 기록물 느낌 |

날짜에 모노스페이스를 쓰면 타임라인이 "아카이브"처럼 보입니다. 작지만 인상을 크게 바꾸는 디테일입니다.

### 카드 & 타임라인

**목표 카드 (홈)**
```
┌─────────────────────────────┐
│ [대표 사진 · 16:9]           │
│                             │
│ 제주도 한 달 살기             │
│ 마지막 기록 12일 전  · 여행    │
│ ─────────────────────────── │
│ 지금 어때요?         [입력]   │  ← 퀵 체크인 인라인
└─────────────────────────────┘
```

**타임라인 (상세)** — 세로선 + 노드 구조. 이 앱의 얼굴이므로 여기에 시간을 가장 많이 씁니다.
```
  │
  ●  04.02
  │  항공권 예약 완료!
  │  [사진]
  │
  ●  03.12
  │  숙소 알아보는 중
  │
  ○  03.01  목표 만듦
```

기록 종류에 따라 노드 모양을 다르게 합니다.
- 퀵 체크인 → 작은 점
- 진행 기록 → 큰 점
- 완료 → 채워진 원 + 체크

### 아이콘

선(line) 아이콘, 두께 1.5px, 라운드 캡. 채워진 아이콘은 선택 상태에만 씁니다.

## 5. 인터랙션 원칙

| 원칙 | 의미 |
|---|---|
| **퀵 체크인은 3초** | 탭 → 입력 → 저장. 화면 전환 없음 |
| **필수 입력 없음** | 사진만, 메모만, 둘 다 모두 허용 |
| **파괴적 동작은 되돌릴 수 있게** | 삭제·완료·접어두기 모두 undo 또는 되돌리기 제공 |
| **로딩 대신 자리 잡기** | 스피너보다 스켈레톤. 사진은 width/height로 미리 자리 확보 |
| **키보드가 화면을 가리지 않게** | 특히 퀵 체크인 |

---

## 6. 접근성

- 최소 터치 영역 48dp
- 본문 대비비 4.5:1 이상
- 시스템 폰트 크기 설정 존중 (고정 sp 금지)
- 모든 이미지에 contentDescription — 사진은 해당 기록의 메모를 사용
- 색만으로 상태를 구분하지 않음 (완료/접어둠은 아이콘도 함께)

□ 미완료를 실패로 규정하고 있지 않은가
